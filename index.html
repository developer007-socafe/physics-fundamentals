How to use this guide

  1. Each topic starts with core concepts and builds up to deeper ideas.
  2. Bold terms (vector) carry quick definitions on hover.
  3. Equations are rendered with MathJax — e.g. $E = mc^2$ — and each section ends with a Key Takeaway.
  4. Green simulations let you drag sliders and see physics in action.
